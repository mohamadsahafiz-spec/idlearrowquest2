# PROJECT RULES — GODOT ONLY

This repository is exclusively a Godot 4.7.1 + GDScript project.

Rules:
- project.godot and scenes/ are the source of truth.
- Never convert, recreate, scaffold, or supplement this project with React, Vite, TypeScript, HTML, or another framework.
- Modify only files required by the current task.
- Preserve working systems and architecture.
- No unsolicited features or refactoring.
- Use Godot-native nodes, scenes, resources, GDScript, and primitives.
- No SVG/media generation unless explicitly requested.
- Keep prompts/task execution compact and scope-focused.
- Update VERSION and CHANGELOG only when instructed by the task.
